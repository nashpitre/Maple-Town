# Contributing to Maple Town

## Start with the current scope

This repository documents a personal family TV build. It does not yet include the complete runtime or a distributable installer. Documentation improvements, clearer diagrams, issue reports, and proposals for a reusable household edition are useful contributions.

## Make a useful report

Describe what you selected, what you expected, what actually appeared, and whether the TV had restarted. For device issues, include model, firmware, and OS version, but omit serial numbers, local addresses, account identifiers, signing material, and tokens.

For YouTube, distinguish these outcomes:

- Correct signed-in home opened directly.
- Chooser appeared with the correct person highlighted.
- Wrong person appeared.
- Sign-in was required.
- Launch failed or stalled.

Those outcomes are not interchangeable.

## Keep the design coherent

Favor legibility from the sofa, a soft preschool-inspired palette, calm spacing, simple recognizable faces, and occasional movement. Explain how a proposed feature helps the family rather than adding visual activity for its own sake.

## Separate evidence from plans

Keep implemented features, local browser checks, on-TV observations, and unfinished work distinct. Update STATUS.md when verified behavior changes. Do not turn an SDK success response into a physical-device claim.

## Respect personal assets

Do not reuse family portraits or the personal house illustration as generic project assets without permission. Do not attach account data or private setup/recovery files to issues. See CREDITS.md for upstream attribution and asset boundaries.
