# Credits and reuse notes

## Maple Town

Maple Town is the creator’s personal family adaptation, shaped by feedback from the household. Its documentation describes the current family installation and its development decisions.

## CleanFrame foundation

The underlying launcher began from [CleanFrame by Nathan Clark](https://github.com/nthnclrk/CleanFrame). Its original code and documentation carry an MIT license with Nathan Clark's copyright notice. The original license is retained here as [LICENSE-CleanFrame](LICENSE-CleanFrame).

This showcase repository does not redistribute the complete application source. If that source is released later, its upstream license, notices, and third-party asset records must travel with it.

## Weather

The application uses [Open-Meteo](https://open-meteo.com/) for current conditions and forecasts. The current runtime query is a location-based weather request. A showcase screenshot may instead use a controlled fixture to illustrate a condition or date.

## Fonts and third-party service marks

The source project's public font options include Manrope, Geist, and Newsreader. Personal builds can differ. Proprietary font binaries are not included in this documentation repository.

Samsung, YouTube, Netflix, Prime Video, Disney+, Hulu, Plex, and DirecTV are names of their respective services. Mentioning them describes native-app integration, not endorsement or affiliation.

## Family artwork and screenshots

The family’s illustrated character icons appear in the public screenshots with the creator’s permission. The custom house illustration is excluded from the demonstration gallery. Public demonstrations omit personal birthday data and the home location. No original personal reference photos, signing keys, account tokens, private device dumps, or signed TV installation packages are included.
