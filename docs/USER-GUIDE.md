## Open a family profile

1. Return to Maple Town using the configured Home path.
2. Move Left or Right to a family face.
3. Check the outline to see which face is selected.
4. Press the center/OK button.

The order in the personal build is five household profiles. Normal loading shows a spinner. The selected face requests that person's native YouTube session.

If YouTube asks you to choose a person or sign in, the shortcut has not completed its intended automatic path. That is a failure to investigate, not normal proof of successful profile switching. Do not change a child's parental controls to make the launcher work.

## Open a streaming app

Move to the app-grid control in the grass at the bottom left and press OK. Choose a service from Favorite apps. The drawer is curated around YouTube, Plex, DirecTV, Netflix, Prime Video, Disney+, and Hulu. Available entries depend on installed-app discovery.

Back returns from the drawer. The service itself handles viewing, accounts, subscriptions, and playback.

## Find all installed apps

Open the bottom-right gear, choose All apps, and select the application you need. This keeps less frequent apps off the main family screen.

Samsung's Apps store and Developer Mode are separate from Maple Town's installed-app list. Opening All apps does not itself open Developer Mode.

## Change an appearance setting

1. Open the gear in the bottom-right grass.
2. Choose a settings group.
3. Move to the desired option.
4. Press OK to apply it.
5. Use Back to close the panel.

Background options include the living local weather view and inherited photo/light/dark styles. Other groups control layout, typography, focus, and Home app arrangement. Some controls depend on the selected background or layout.

The current family view is tuned around the weather landscape and portraits. A different background or layout can change the composition shown in the gallery.

## Read the weather and calendar

The upper-left area shows the clock, local weather, and five upcoming forecast days. Each day uses a condition icon with high and low temperatures. The upper-right area shows the current month and countdowns.

Today is highlighted in the calendar. A starred event date is connected to a highlighted countdown row for the same month. Upcoming events outside the visible month can still appear in the three-month countdown.

## What updates by itself

| Item | Automatic behavior |
| --- | --- |
| Clock | Uses the TV's date and time. |
| Weather | Requests updated conditions about every five minutes while active. |
| Sky phase | Repaints while visible and uses reported sunrise/sunset times. |
| Forecast | Rebuilds from valid weather data and skips today. |
| Calendar | Advances when the date changes. |
| Countdowns | Recalculate with the day and roll across year boundaries. |
| Stars | Keep one evening's arrangement through midnight, then change the next evening. |
| Character and scenery | Animate while active, with pauses for hidden screens and reduced motion. |

## Troubleshooting

### A face opens a chooser

Note which face you pressed, whether the TV had restarted, and which person was highlighted. If possible, record the visible result before manually selecting someone. The latest launch correction passed all five face tests, but full restart retention still needs verification.

### YouTube asks for sign-in

This is different from merely seeing a chooser. Record the affected person and restart history. Use YouTube's normal account flow if signing in is needed; Maple Town does not collect account passwords.

### Weather looks old or unavailable

Check the TV's internet connection and date/time. The app can retain recent cached weather during a temporary failure, then shows unavailable data after its age limit. It retries without requiring a Mac.

### The calendar date is wrong

Check Samsung's system date, timezone, and automatic clock settings. The current calendar uses the TV's date; it is not synced to a separate calendar service.

### A favorite app is absent

Check All apps and whether the native service is installed. The curated drawer is a launcher, not an app installer.

### Restart opens Samsung Home or live TV

This remains a known integration issue. It is separate from whether Maple Town itself installed and runs. Use the working Home route where available; do not remove Samsung recovery paths while investigating.

### The three branded buttons still open their original services

Permanent Netflix/Prime/TV Plus button remapping has not been verified. The proposed family mappings are documented as unfinished work.
