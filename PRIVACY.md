# Public showcase privacy

Reviewed October 25, 2026.

## What the public examples contain

The public gallery uses the family’s illustrated character icons, shared with the creator’s permission, a sample town label, simulated weather, standard holidays, and fictional demonstration dates. It is rendered from the interface for illustration; it is not a capture of a household account or a live forecast.

## Creator-supplied story images

[I Created Maple Town](docs/STORY.md) reproduces the creator’s supplied blog post and six image links at the creator’s request. These externally hosted images are an explicit exception to the demonstration gallery: they may show household artwork chosen for that post. Image content is preserved; equivalent creator-website URLs may be used where a CDN link does not render through GitHub’s image proxy. No original family photographs, portrait source files, birthdays, account data, or private setup files are added to this repository by that story.

## What is excluded from the public demonstration gallery

- Household members’ names and original family photographs. The approved cartoon character icons are intentionally included.
- Personal birthdays, countdowns, and calendar markers.
- A real home's appearance and location.
- Account identifiers, account relationships, sign-in screens, or viewing history.
- Private contact addresses, local network addresses, device serials, and unique installation IDs.
- Credentials, tokens, cookies, signing keys, recovery files, or signed installation packages.
- Personal image metadata and the original unreviewed repository history.

## History and commit identity

The public repository begins with a new history containing reviewed files only. GitHub's no-reply author address is used for web commits. The repository owner’s GitHub username and public GitHub profile remain visible, as on other public repositories.

## Review performed

The publication set was checked for personal names, locations, contact addresses, local paths, network addresses, common token patterns, private file types, and links to excluded images. Screenshot fixtures remove private calendar events before rendering, use the approved family character icons, and remove the custom house artwork. PNG files were checked for text and EXIF metadata. Public repository files and commit metadata are checked again after upload.

This is a bounded review, not a guarantee against every possible inference. Future screenshots, issue attachments, documentation changes, and commits need the same care.

## The installed TV

These changes affect the public showcase only. They do not remove the household's personal portraits, birthday configuration, location, or house illustration from its private TV installation.
